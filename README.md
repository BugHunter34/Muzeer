Muzeer 🎵

Modern music streaming platform built with React, Node.js, Python and MongoDB.

Features

- User authentication (JWT)
- Email verification
- 2FA security
- Profile management
- Avatar upload
- Admin panel
- Playing of songs

Tech Stack

Frontend
- React
- Vite
- CSS

Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Python
- JWT

Installation

Clone repository

git clone https://github.com/BugHunter34/Muzeer.git

#Install dependencies

cd client
npm install

cd server
npm install

Start project

client:
npm run dev

server:
npm start

python run code

Environment Variables

Create .env file:

DATABASE=
JWT_SECRET=
EMAIL_USER=
EMAIL_PASSWORD=
